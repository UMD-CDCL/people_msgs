# people_msgs

ROS 2 conversion of the `people_msgs` package, originally based on [wg-perception/people](https://github.com/wg-perception/people).

## Overview
This package provides the message definitions needed for human-aware navigation. It is primarily used for adding people to the Nav2 costmap in conjunction with the [nav2_social_costmap_plugin](https://github.com/robotics-upo/nav2_social_costmap_plugin).
